# THIS MOD DOES NOT HIDE YOUR OWN CHEATS

This mod simply prevents the 🛑 CHEATER 🛑 tag from being applied to _other_ players if they specifically use a DLC unlocker.

Whenever someone triggers this mod's preventions you will get a notification in chat that the marking was prevented. You can disable this chat notification by going into the networkpeer.lua file and changing the first variable from _true_ to _false_.

This mod only affects your POV - other players still see the cheater tag above players with DLC unlocker.

Works regardless of if you are a lobby client or host.

For a long while before the 64bit update, the PD2's anticheat worked in a way where DLC unlock players weren't getting auto-kicked if the host had the "auto-kick cheaters" option enabled, and neither were they getting the red marker above their heads, while players who deploy too many ammo bags or spawn in loot bags were marked and auto-kicked. This mod replicates this behavior by preventing DLC-cheater markings from happening.

I personally do not care for other people's monetary capabilities, and i'm also extremely annoyed by the red marker that would float above players if they are marked, thus this mod's creation.
